Crop Yield Monitoring System

The Crop Yield Monitoring System is a Python-based application developed for the PROG211 Object-Oriented Programming 1 individual assignment. The project focuses on the agriculture domain and demonstrates how programming can help farmers record and monitor crop production.

The system allows users to enter crop information, including the crop name, farm area in hectares, and harvested quantity in kilograms. It calculates the crop yield per hectare and displays the recorded information in an organized format.

The application uses Object-Oriented Programming (OOP) concepts through two main classes: CropRecord and CropMonitoringSystem. The CropRecord class stores crop details and contains methods for calculating yield and displaying records. The CropMonitoringSystem class manages the application and interacts with crop objects.

The project demonstrates important programming concepts such as classes, objects, attributes, methods, and object interaction. It can also be extended to store multiple crop records using a Python list, validate user input, and provide additional crop production reports.

The system aims to provide a simple, understandable, and reusable approach to agricultural record-keeping. In line with Digital Public Goods principles, the project can be shared as open-source software, designed with an accessible text-based interface, and developed with consideration for user privacy.

In conclusion, the Crop Yield Monitoring System provides a practical demonstration of Python programming and object-oriented design while exploring how digital technology can support agricultural productivity and record management.
